Assets · Step 2 of 3

Tell Flutter in pubspec.yaml

pubspec.yaml
flutter:
  uses-material-design: true
  assets:
    - assets/images/
assets:The list of asset folders or files
- assets/images/Every file in this folder. Don't forget the / at the end!
Spaces matter! assets: has 2 spaces, - assets/… has 4. Never use Tab.
Save the file. VS Code runs flutter pub get for you.

Image tip

fit: how a picture fills its box

Same Chrollo, same square box, three different BoxFit values:

BoxFit.coverFills the box, cuts the edges
BoxFit.containShows all of it, leaves space
BoxFit.fillStretches it (Chrollo looks wrong!)
Mobile App Development · Lecture 06

BoxFit.cover is the one used most for photos. contain is good for logos. fill almost always looks bad: look at Chrollo's face.

Way 3 · SVG

What is an SVG?

JPG and PNG pictures are made of tiny squares (pixels). An SVG is a drawing made of shapes, saved as text, so it stays sharp at any size.

zoom × 3

JPG / PNG

Zoom in → you see the squares. Best for photos.

zoom × 3

SVG

Zoom in → still sharp. Best for logos, icons, drawings.

phantom_spider.svg

<!-- an SVG file is just text -->
<svg viewBox="0 0 240 230">
  <circle cx="120" cy="94" r="15"/>
  <ellipse rx="24" ry="33" …/>
  <path d="M112 104 L115 58…"/>
</svg>

circle = head, ellipse = body, path = one leg. The phone draws the shapes again at any size.

Mobile App Development · Lecture 06

SVG = Scalable Vector Graphics. Open phantom_spider.svg in VS Code to show it really is text. Then open it in the browser: the same text becomes the spider.

This spider is the emblem of the Phantom Troupe, the group Chrollo leads.

SVG · Step 1 of 3

Add the flutter_svg package

Flutter can't show SVG files on its own. A package is ready-made code that other developers share on pub.dev.

flutter_svg2.3.0

Draws SVG files in Flutter apps. Works on Android, iOS, web and desktop.

pub.dev/packages/flutter_svg
This is our first package! Later we'll add more the same way.
Terminal (in your project folder)
PS> flutter pub add flutter_svg
Resolving dependencies...
+ flutter_svg 2.3.0
# done! it was added to pubspec.yaml ↓
pubspec.yaml

  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8
  flutter_svg: ^2.3.0

SVG · Step 3 of 3

Import it, then use SvgPicture

lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';

// … inside build():
SvgPicture.asset(
  'assets/svg/phantom_spider.svg',
  width: 150,
)
The importOpens the package so this file can use it. Put it at the top.
SvgPicture.assetLike Image.asset, but for SVG files.
width: 150Any size you want. It stays sharp.

Forgetting the import is the number one SVG error: "Undefined name 'SvgPicture'". VS Code can add it for you: click on SvgPicture → Quick Fix (Ctrl + .) → Import library.

SVG · Two more tricks

SVG from the internet, in any color

From the internet 
SvgPicture.network(
  'https://monther-bug.github.io/flutter-lecture-06/assets/svg/phantom_spider.svg',
  width: 80,
)
Needs internet, like Image.network
Change its color 
SvgPicture.asset(
  'assets/svg/phantom_spider.svg',
  width: 80,
  colorFilter: const ColorFilter.mode(Colors.deepPurple, BlendMode.srcIn),
)
BlendMode.srcIn paints the whole drawing in one color

Troubleshooting

6 picture mistakes (and the fix)

Unable to load asset: "assets/images/chrollo_book.jpg"Check the path and file name, and that the folder is listed in pubspec.yaml.
New picture doesn't show upStop the app and run it again. New assets need a full restart.
Error on line 64, column 5 … pubspec.yamlWrong spaces in pubspec.yaml. Use 2 and 4 spaces, never Tab.
Undefined name 'SvgPicture'Add import 'package:flutter_svg/flutter_svg.dart'; at the top.
Exception: Invalid image dataYou used Image.asset on an .svg file. Use SvgPicture.asset.
SocketException: Failed host lookupNo internet, or a wrong URL in Image.network.
Names are case-sensitive: Chrollo.JPG and chrollo.jpg are two different files.
